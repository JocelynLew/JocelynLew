### 📌 Key Projects

**🏠 [Machine Learning Classification of Airbnb Hosts](https://github.com/JocelynLew/-My-Cornell-Portfolio)** — *Break Through Tech AI / Cornell AI Program, 2026*
Built and evaluated three classification models (Logistic Regression, KNN, Decision Trees) to predict Airbnb Superhost status across ~28,000 listings, reaching 80.8% accuracy with a tuned Logistic Regression model. Handled feature engineering, missing data, and hyperparameter tuning with GridSearchCV, and implemented Logistic Regression from scratch to benchmark against scikit-learn.
`Python` `Pandas` `scikit-learn` `GridSearchCV`

**📊 Correlation Study on Interviewer and Respondent Biases** — *2024*
Designed an experimental cluster study testing whether interviewer appearance biases respondent honesty, cutting sampling bias by 50% and surveying ~500 students. Authored a full statistical report interpreting the findings.
`Experimental Design` `Statistical Analysis`

**🏥 Public Health Data Analysis: Income & Diabetes Prevalence** — *2025*
Used linear regression on LA County public health datasets to quantify the relationship between income and Type 2 diabetes prevalence, and built a Python pipeline to manage and process the data.
`Python` `Regression` `Data Cleaning`
